# kids-code-lab: «Εργαστήρι Κώδικα»

The family's kids make their own small arcade games with blocks (MakeCode Arcade, built as a static offline site),
play them on the PC or tablet and, with a parent's family code, publish a finished game to a shelf in «Τα Παιχνίδια
μας» (games-hub). No accounts, no cloud, nothing leaves the house.

**Status: spike (L1-27).** Nothing is built or deployed yet. The approved spec is
[docs/specs/KIDS-CODE-LAB.md](docs/specs/KIDS-CODE-LAB.md). The first step is the one-day spike of spec §4 (size of the
static build, CSP, service worker, zero external calls, fonts, Greek, export format); its report goes to
`docs/spike/`. The README sections of GAME-STANDARD v1.3 §2a (test list `KCL-01..`) come with the build.
